## Overview

NewsBot is an eight-module NLP project that processes, analyzes, and classifies news articles from the BBC News Classification dataset.

## Dataset

[BBC News Classification on Kaggle](https://www.kaggle.com/competitions/learn-ai-bbc/data) — download `BBC News Train.csv` (1,490 records before cleaning; five categories: Business, Entertainment, Politics, Sport, and Tech).

## Files

- `ITAI2373_NewsBot_Midterm.ipynb` — notebook with the eight NLP modules.
- `NewsBot_Group_Reflection.docx` — group reflection document.

## How to Run

1. Download the `.ipynb` file and open it in [Google Colab](https://colab.research.google.com/).
2. Download `BBC News Train.csv` from Kaggle.
3. Run the notebook cells in order.
4. Upload the CSV when the notebook prompts you.
5. Review the outputs, visualizations, classification results, and reflection answers.

## What I Learned

I worked on defining the business problem, exploring the dataset, and preparing text through cleaning, tokenization, stop-word removal, and lemmatization. The project showed how preprocessing connects to feature extraction, grammatical analysis, classification, sentiment analysis, and entity recognition.

## Applications

Automated news categorization, media monitoring, sentiment analysis, and information extraction.
